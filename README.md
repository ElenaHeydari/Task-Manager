
# — Task Manager

A responsive task management app built with vanilla HTML, CSS, and JavaScript.

## Features

- Create, edit, complete, and delete tasks
- Set task priorities and due dates
- Search tasks by title or description
- Filter tasks by status
- Sort by creation date, due date, or priority
- Track completion statistics and progress
- Persist tasks using browser localStorage
- Responsive desktop and mobile layouts

## Tech Stack

- HTML5
- CSS3
- Vanilla JavaScript
- Browser localStorage API

## Run Locally

Clone or download the repository and open `index.html` in your browser.

No dependencies or build tools are required.

## Data Storage

Tasks are stored locally in the browser. They are not synced between devices or browsers.

## Deployment

Deploy the project using GitHub Pages.
